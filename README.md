# Workforce Program Data Analysis & Dashboard (Due to I Use a mock dataset (or publicly available workforce dataset)
## Project Description
Analyzed workforce program data to understand training effectiveness, success rates, and program impact. Built visualizations in Python and a dashboard in Power BI.
## Technologies Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Power BI
- CSV Data Files
## Steps
1. Data Cleaning & Transformation (ETL)
2. Statistical Analysis
3. Visualizations in Python
4. Dashboard in Power BI
## Results
- Success rates for each program
- Correlation between training hours and participant success
- Interactive Power BI dashboard for program monitoring
## Files
- `workforce_data.csv` – Raw data  
- `workforce_data_cleaned.csv` – Cleaned data  
- `data_cleaning_analysis.ipynb` – Python analysis notebook  
- `visualizations/` – Python charts  
- `power_bi_dashboard.pbix` – Power BI dashboard
